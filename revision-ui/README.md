# revision-ui/ — capturas de errores de la revisión del cockpit

Deja aquí las **capturas de pantalla** de cualquier error/comportamiento raro que
encuentres revisando COMPAS en el navegador. Claude Code las lee desde esta carpeta.

## Cómo usarla
1. Guarda cada captura aquí con un nombre descriptivo, p. ej.:
   - `error-inicio-caja-mal.png`
   - `error-dashboards-mora-vacia.png`
   - `proyeccion-no-carga.png`
2. Avísame en el chat ("subí capturas a revision-ui") y las reviso una por una.
3. Opcional: al lado de cada imagen, un `.txt` con la URL/vista y qué esperabas.

## Privacidad

capturas pueden mostrar data financiera real y **NUNCA** se suben al repo (regla 12 /
Ley 1581). Bórralas cuando terminemos la revisión.
